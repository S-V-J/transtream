About TranStream

TranStream is a local-first audio studio for real-time microphone transcription, uploaded audio transcription, language detection, translation, and text-to-speech playback.

Planned Pipeline

  1. Browser captures microphone audio.
  2. Audio is sliced into 100 ms chunks.
  3. Chunks stream over WebSocket.
  4. FFmpeg normalizes audio to 16 kHz mono PCM.
  5. Silero VAD detects speech segments.
  6. Faster-Whisper transcribes segments.
  7. Argos Translate translates locally.
  8. Piper generates local voice playback.

Current Status

  • Phase 0: repository initialized.
  • Phase 1: Django + Channels + base UI scaffold.
  • Phase 2: live microphone WebSocket ingestion.
  • Phase 3: FFmpeg normalization.
  • Phase 4: VAD and long audio chunking.
  • Phase 5: Faster-Whisper transcription and LID.
  • Phase 6: translation.
  • Phase 7: TTS.
  • Phase 8: workspace and storage management.
  • Phase 9: upload pipeline.
  • Phase 10: PWA and production polish.
